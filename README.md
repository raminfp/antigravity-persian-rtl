# فارسی‌ساز، فونت وزیرمتن و جعبه ابزار هوشمند Antigravity

ابزار سبک، بدون وابستگی خارجی و **مقاوم در برابر آپدیت** برای راست‌چین‌سازی استاندارد (**RTL**) و نمایش فونت **وزیرمتن (Vazirmatn)** در محیط چت **Antigravity Desktop (2.0)** و **Antigravity IDE** روی **ویندوز و لینوکس**.

![پیش‌نمایش فارسی‌ساز، فونت وزیرمتن و جعبه ابزار بالای Antigravity](docs/preview.png)

---

## ویژگی‌های کلیدی

- **تایپوگرافی استاندارد فارسی با فونت وزیرمتن (Vazirmatn):** پشتیبانی کامل از وزن‌های مختلف فونت محلی وزیرمتن (به‌صورت آفلاین) و فونت گوگل به‌عنوان پشتیبان.
- **تشخیص هوشمند جهت متن (حتی برای جملات ترکیبی):** پاراگراف‌ها، تیترها، لیست‌های شماره‌دار و بولت‌دار، نقل‌قول‌ها، جداول، کارت‌های سوال چندگزینه‌ای (`ask_question`) و کادر تایپ چت—حتی اگر با یک کلمه انگلیسی مثل `Antigravity` یا `React` شروع شده باشند—راست‌چین می‌شوند و پیام‌های کاملاً انگلیسی چپ‌چین (`LTR`) می‌مانند.
- **حفظ کامل `LTR` برای کدها و ترمینال:** بلوک‌های کد (`pre`)، کدهای درون‌خطی (`code`)، ادیتور کد (`Monaco`)، ترمینال (`xterm`)، فرمول‌های ریاضی (`KaTeX`) و پنجره مرورگر داخلی ایجنت کاملاً ایزوله و چپ‌به‌راست باقی می‌مانند.
- **جعبه ابزار کنترلی در نوار بالای برنامه (`فارسی ⚙`):**
  - کلید روشن/خاموش آنی فارسی‌ساز + میانبر صفحه‌کلید `Alt + Shift + R`
  - انتخاب بین ۳ حالت جهت‌دهی: **هوشمند (`Smart`)**، **خودکار (`Auto`)** و **همیشه راست (`Force RTL`)**
  - تغییر زنده فونت (**Vazirmatn**، **Vazir**، **Tahoma**، **Segoe UI** یا هر فونت دلخواه نصب‌شده روی سیستم مثل `IRANSansX` و `Yekan Bakh`)
  - تنظیم زنده اندازه نوشتار فارسی (`85%` تا `135%`) و فاصله خطوط (`فشرده`، `استاندارد`، `باز`)
  - **نمایش اعداد فارسی (`۰-۹`) بدون تغییر در کپی متن:** با ویژگی OpenType `ss01` فونت وزیرمتن، اعداد داخل متن فارسی به شکل فارسی دیده می‌شوند اما هنگام `Copy` و در بلوک‌های کد همچنان اعداد استاندارد انگلیسی باقی می‌مانند.
  - ذخیره خودکار تمام تنظیمات بین نشست‌ها و هماهنگی خودکار با تم تاریک و روشن برنامه.
- **لانچر هوشمند مقاوم در برابر آپدیت (بدون پنجره سیاه):**
  - ساخت شورتکات‌های اختصاصی **`Antigravity RTL`** و **`Antigravity IDE RTL`** روی دسکتاپ و منوی استارت.
  - بررسی وضعیت پچ در کمتر از ۶ میلی‌ثانیه هنگام باز کردن برنامه؛ در صورت نصب آپدیت جدید Antigravity، به‌صورت خودکار از نسخه جدید بکاپ می‌گیرد، پچ را اعمال می‌کند و برنامه را اجرا می‌کند.
- **بدون نیاز به Node.js یا ابزار خارجی در زمان اجرا:** بازسازی کامل هدر باینری `app.asar` و هش‌های `SHA-256` تنها با کتابخانه استاندارد پایتون ۳.

## پیش‌نیازها

- سیستم‌عامل **ویندوز ۱۰ / ۱۱** یا **لینوکس**
- **Python 3** نصب‌شده روی سیستم
- **فونت Vazirmatn** (پیشنهادی برای نمایش آفلاین؛ در صورت نبودن، از Google Fonts بارگذاری می‌شود)

## نصب و راه‌اندازی (در ۱ مرحله)

۱. مخزن را کلون یا به‌صورت ZIP دانلود و استخراج کنید:

</div>

```bash
git clone https://github.com/Prot0nX/antigravity-persian-rtl.git
cd antigravity-persian-rtl
```

<div dir="rtl">

۲. **روی ویندوز:** روی فایل **`Install-RTL.bat`** دابل‌کلیک کنید:
- شورتکات‌های **`Antigravity RTL`** و **`Antigravity IDE RTL`** روی دسکتاپ و منوی استارت ساخته می‌شوند.
- نسخه **Antigravity IDE** و **Antigravity Desktop** پچ شده و برنامه با ظاهر فارسی، فونت وزیرمتن و جعبه ابزار بالای صفحه باز می‌شود.

۳. **روی لینوکس:** اسکریپت نصب لینوکس را اجرا کنید:

</div>

```bash
chmod +x install-rtl.sh patch-now.sh uninstall-rtl.sh antigravity_rtl.py
./install-rtl.sh
```

<div dir="rtl">

- مسیر نصب Antigravity به‌صورت خودکار (از جمله از روی اسکریپت‌های wrapper در `PATH` مثل `~/.local/bin/antigravity` و مسیرهای `/opt` و `~/.local/share`) شناسایی می‌شود.
- شورتکات‌های `.desktop` با نام **`Antigravity RTL`** در `~/.local/share/applications/` (و دسکتاپ) ساخته می‌شوند و هنگام اجرا، فلگ‌های wrapper کاربر (مثل `--proxy-server` و `--no-sandbox`) حفظ می‌شوند.
- برای مسیرهای سیستمی مثل `/opt/antigravity` می‌توانید با `sudo python3 antigravity_rtl.py patch --target all --no-shortcuts` پچ کرده و سپس با `python3 antigravity_rtl.py install-shortcuts` شورتکات کاربری بسازید.

> از این پس برای باز کردن برنامه از شورتکات **`Antigravity RTL`** استفاده کنید تا پس از هر بار آپدیت شدن Antigravity، فارسی‌سازی به‌طور خودکار حفظ شود.

## فایل‌های پروژه

| فایل | کاربرد |
| --- | --- |
| `Install-RTL.bat` / `install-rtl.sh` | نصب تعاملی شورتکات‌ها و اعمال اولیه پچ (ویندوز / لینوکس) |
| `Patch-Now.bat` / `patch-now.sh` | اعمال فوری آخرین نسخه پچ (ویندوز / لینوکس) |
| `Uninstall-RTL.bat` / `uninstall-rtl.sh` | حذف کامل شورتکات‌های RTL و بازگرداندن فایل‌های اصلی برنامه به حالت کارخانه (بایت‌به‌بایت) |
| `antigravity_rtl.py` | موتور پچر خالص پایتون (`ASAR` + `IDE`)، مدیریت کش و شورتکات‌ها |
| `assets/agy-rtl.css` | استایل فونت وزیرمتن، تایپوگرافی RTL و ظاهر جعبه ابزار بالای برنامه |
| `assets/agy-rtl.js` | موتور `MutationObserver` و پنل تنظیمات زنده (کاملاً سازگار با `Trusted Types`) |
| `launch-desktop.vbs` / `launch-ide.vbs` | لانچرهای مخفی بدون نمایش پنجره سیاه ترمینال |
| `test_antigravity_rtl.py` | مجموعه تست خودکار بررسی صحت باینری `ASAR`، شبیه‌سازی آپدیت، بازگردانی بکاپ و منطق DOM |

## دستورات خط فرمان (CLI)

</div>

```powershell
# بررسی وضعیت فعلی پچ
python antigravity_rtl.py status

# اعمال اجباری پچ روی هر دو نسخه دسکتاپ و IDE
python antigravity_rtl.py patch --target all --force

# بازگرداندن فایل‌های اصلی به حالت اولیه
python antigravity_rtl.py restore --target all

# اجرای مجموعه تست‌های خودکار
python test_antigravity_rtl.py
```
